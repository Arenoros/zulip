# Use Zulip conversations for call chat

A call opens the Zulip conversation where it started, so participants can read and send messages alongside the call using the usual conversation permissions. When an invited user joins a direct message call, the call chat switches to the group direct message for the expanded set of recipients, with any history already visible to that group. Messages from the original conversation stay there, and a channel call keeps its original topic.

The direct message recipient set includes the caller, the original recipients, and invitees who have joined the call. It only grows while the call is active. A participant can leave or reconnect without changing which conversation everyone sees.
