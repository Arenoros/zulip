# Use Zulip conversations for call chat

A call opens the Zulip conversation where it started, so participants can read and send messages alongside the call using the usual conversation permissions. When a user is invited to a direct message call, the inviter posts the call's link to the group direct message for the expanded set of recipients, and the call chat switches to it right away, with any history already visible to that group. That message also gives a user who missed the invitation a conversation to find the call in. Messages from the original conversation stay there, and a channel call keeps its original topic.

The direct message recipient set includes the caller, the original recipients, and everyone invited to the call, whether or not they joined it. It only grows while the call is active. A participant can leave or reconnect without changing which conversation everyone sees.
