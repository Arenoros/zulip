* [`POST /calls/livekit/invite`](/api/invite-to-livekit-call),
  [`GET /events`](/api/get-events): Added an endpoint to call users to
  join a LiveKit call that is going on, and a new `call op:rings` event
  with who is being called to a call. Users called to a direct message
  call can join it, and answer the call with
  [`POST /calls/livekit/ring`](/api/update-livekit-call-ring).
