* [`POST /register`](/api/register-queue), [`PATCH /settings`](/api/update-settings),
  [`PATCH /realm/user_settings_defaults`](/api/update-realm-user-settings-defaults):
  Added `5`, "Conversations", as a new value of the
  `web_channel_default_view` display setting, with which the web app
  shows a channel as a list of topic cards. It is the new default,
  replacing `1`, "Top topic in the channel"; the setting of existing
  users and the organization defaults were changed to it as well.
